# Applikasjonsutvikling Eksamen 2025

> **Note:** The application does not provide a `BASE_URL` or `API_KEY` due to ethical/academic reasons. The key still works and can be provided upon request.

## About project
This project was developed as the final exam for **MM-206 Applikasjonsutvikling 1** at the University of Agder. The task was to build a Single Page Application (SPA) communicating with a provided REST API using an API key. 

The application is a web store where users can browse and order different chocolates. It also includes an administrative dashboard for managing products and overseeing user activity.

---
## Tech Stack 
* **JavaScript (ES6+)**: Built entirely with vanilla JavaScript (no frameworks).
* **HTML5 / CSS3**

---
## Functionality

### User Client
* **Authentication:** Create an account and log in.
* **Profile Management:** Edit profile details (profile picture, name, etc.).
* **Exclusive Content:** View exclusive chocolates accessible only with a valid auth token.
* **Store & Filter:** Browse the store and filter through different chocolates.
* **Cart System:** Fully functional shopping cart for users.
* **Orders:** Place new orders and view order history.
* **Reviews:** Review chocolates and delete personal reviews.
* **Community Forum:** Create threads and comment (requires login).

### Admin Client
* **Product Management:** Add new chocolates and restock existing items.
* **User Overview:** View a list of all registered users, including their orders, reviews, and comments.
* **Moderation:** Delete any user's reviews or comments.
